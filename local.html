Kho local của bạn.

Tài khoản này thuộc instance đang chạy. Không dùng OTP demo, không cần tài khoản cộng đồng.

Kho riêng, chạy trên máy bạn.

Trang đang mở là bản website tĩnh. Để tạo hồ sơ và lưu tư liệu riêng, chạy server local bằng Node hoặc Docker theo hướng dẫn.

npm ci
npm run build
npm run start:local
